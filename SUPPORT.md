# Support

Choose the channel that matches your request.

## Project bugs

Use the issue tracker in the affected repository. Include:

- the project version or commit;
- operating system and runtime version;
- steps to reproduce the problem;
- expected and actual behavior;
- relevant logs with secrets removed.

Do not use public issues for vulnerabilities or credentials.

## Project questions and ideas

- [Discord](https://discord.gg/fjqzSYCETC) for community discussion and project help.
- [Telegram](https://t.me/DigitalHorizon) for community updates and general contact.
- Repository issues for concrete, reproducible bugs and actionable feature requests.
