# Security Policy

## Supported versions

Security fixes are provided for actively maintained repositories and their current default branches. Individual projects may define a more specific support table.

Experimental, archived, or unmaintained projects may not receive security updates. Check the project README for its current status.

## Report a vulnerability

Do not disclose a suspected vulnerability in a public issue, pull request, discussion, Discord channel, or Telegram chat.

Send a private report to [hello@digitalhorizon.group](mailto:hello@digitalhorizon.group) with:

- the affected repository and version or commit;
- a clear description of the problem;
- steps to reproduce it;
- the expected impact;
- relevant logs, screenshots, or proof-of-concept code;
- any suggested mitigation.

Remove credentials, personal data, and unrelated private information from the report.

## What to expect

We will acknowledge a complete report when it has been reviewed, assess whether the issue affects supported code, and coordinate disclosure when a fix is available.

Response and remediation times depend on severity, project status, maintainer availability, and the quality of the report. We do not promise a fixed response time.

## Scope

This policy covers source code and configuration maintained in Digital Horizon Group repositories. Third-party services, dependencies, and infrastructure outside our control may require reporting to their respective maintainers.
